# Bíblia + Chimarrão — Site Institucional

Projeto separado do aplicativo PWA oficial.

## Objetivo
Criar a presença institucional e orgânica do ecossistema Bíblia + Chimarrão, do devocional **Chimarrão com Deus — 365 Encontros com Deus** e do autor **Romulo Schutz**.

## Regras
- Não alterar o aplicativo a partir deste repositório.
- Não inventar telas do aplicativo.
- Usar apenas fotografia real do autor.
- Usar somente o carimbo/logotipo oficial aprovado.
- Não representar o rosto de Jesus ou de Deus.
- SEO é parte estrutural do projeto.

## Desenvolvimento
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Saída estática: `dist/`.

## Publicação
Planejada para Cloudflare Pages. A URL pública será confirmada antes de inserir canonical, sitemap e links para o aplicativo.
